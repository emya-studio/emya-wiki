# ماژول‌های مبدل امیا

ماژول‌های تبدیل سطوح ولتاژ، ایزولاسیون سیگنال و رابط‌های ارتباطی سخت‌افزار.

## دسته‌بندی ماژول‌های مبدل

| نام ماژول | کاربرد اصلی | ولتاژ کاری | مشخصات فنی |
| :--- | :--- | :--- | :--- |
| **[مبدل USB به UART](/converters/usb-to-uart)** | اتصال میکروکنترلر به رایانه و پروگرم فریم‌ور | 3.3V / 5.0V | بادریت تا 3Mbps با پشتیبانی از CTS/RTS |
| **[مبدل باک DC-DC سنکرون](/converters/dcdc-buck)** | تبدیل ولتاژهای صنعتی و باتری به ریل 3.3V | ورودی 4.5V-28V | جریان خروجی 2A با بازده بالای ۹۲ درصد |
| **[مبدل سطح ولتاژ منطقی](/converters/level-shifter)** | ارتباط امن بین قطعات 1.8V، 3.3V و 5.0V | دوجهته (Bidirectional) | فرکانس تبادل تا 20MHz بدون مقاومت خارجی |
