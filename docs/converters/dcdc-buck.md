# ماژول مبدل باک سنکرون DC-DC

مبدل کاهنده ولتاژ فوق کم‌تلفات مناسب برای تجهیزات باتری‌محور و منابع تغذیه صنعتی تا 28 ولت.

## مشخصات فنی و بازده انرژی

| پارامتر | مقدار | واحد | توضیحات |
| :--- | :--- | :--- | :--- |
| **محدوده ولتاژ ورودی ($V_{IN}$)** | 4.5 تا 28 | V DC | مناسب برای ورودی‌های 12V و 24V صنعتی |
| **ولتاژ خروجی ($V_{OUT}$)** | 3.3 | V DC | دقت تثبیت ولتاژ $\pm 1.5\%$ |
| **حداکثر جریان خروجی** | 2.0 | A | با خنک‌کاری طبیعی هوا |
| **فرکانس کاری سوییچینگ** | 500 | kHz | کاهش ریپل ولتاژ خروجی به کمتر از 20mV |
| **راندمان در بار 500mA** | 93.4 | % | در ولتاژ ورودی 12V |
