# ماژول مبدل سطح ولتاژ منطقی (Level Shifter)

مبدل ۸ کاناله دوطرفه سطوح منطقی دیجیتال جهت ارتباط سنسورها و میکروکنترلرهای با ولتاژهای کاری متفاوت.

## ویژگی‌ها و نحوه سیم‌کشی

| پارامتر | سمت A (ولتاژ پایین) | سمت B (ولتاژ بالا) |
| :--- | :--- | :--- |
| **محدوده ولتاژ مجاز** | 1.2V تا 3.6V | 1.65V تا 5.5V |
| **تعداد کانال‌ها** | ۸ کانال مستقل دوطرفه | ۸ کانال مستقل دوطرفه |
| **سازگاری با پروتکل‌ها** | I2C, SPI, UART, 1-Wire | I2C, SPI, UART, 1-Wire |
| **جهت انتقال** | تشخیص خودکار جهت داده بدون پین کنترل جهت (Direction Pin) |
