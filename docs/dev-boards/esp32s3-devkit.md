# برد توسعه Emya ESP32-S3 DevKit

برد مرجع توسعه امیا بر پایه ماژول وای‌فای و بلوتوث ESP32-S3.

## دیاگرام پین‌ها و پایه‌ها (Pinout)

```
                       ┌──────────────────────┐
            [3.3V OUT] │ [ ]              [ ] │ [GND]
                 [GND] │ [ ]              [ ] │ [GPIO0  / BOOT]
              [GPIO1]  │ [ ]              [ ] │ [GPIO43 / U0TXD]
              [GPIO2]  │ [ ]              [ ] │ [GPIO44 / U0RXD]
              [GPIO4]  │ [ ]  ESP32-S3    [ ] │ [GPIO18 / USB D-]
              [GPIO5]  │ [ ]  DevKit      [ ] │ [GPIO19 / USB D+]
              [GPIO6]  │ [ ]   (Emya)     [ ] │ [GPIO21]
              [GPIO7]  │ [ ]              [ ] │ [GPIO47]
              [GPIO15] │ [ ]              [ ] │ [GPIO48 / RGB LED]
             [5V (IN)] │ [ ]              [ ] │ [RESET / EN]
                       └───────┬──────┬───────┘
                               │ USB1 │ USB2 │
                               └──────┴──────┘
                               (UART)  (OTG)
```

## مشخصات درگاه‌های تایپ‌سی

1. **پورت USB1 (UART / Debug)**:
   - متصل به مبدل سریال برای دریافت لاگ‌های نرم‌افزاری و پروگرم فریم‌ور با بادریت تا 921600.
2. **پورت USB2 (Native USB-OTG)**:
   - اتصال مستقیم به پایه‌های USB داخلی ESP32-S3 جهت شبیه‌سازی موس/کیبورد (HID)، دیسک درایو (MSC) و JTAG سخت‌افزاری.

## جدول قطعات کلیدی برد

| قطعه | پارت نامبر | نقش در مدار |
| :--- | :--- | :--- |
| **میکروکنترلر** | ESP32-S3-WROOM-1-N8R2 | پردازشگر اصلی با 8MB Flash و 2MB PSRAM |
| **رگولاتور ولتاژ** | AP2112K-3.3 | تامین جریان پایدار 600mA روی ریل 3.3 ولت |
| **ال‌ای‌دی آدرس‌پذیر**| WS2812B (RGB) | متصل به پایه `GPIO48` جهت نمایش وضعیت برد |
