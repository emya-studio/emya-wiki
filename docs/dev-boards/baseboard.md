# برد پایه آزمایشگاهی امیا (Lab BaseBoard)

برد توسعه جامع جهت اتصال ماژول‌های پردازشی، نمایشگرهای TFT و سنسورهای محیطی در محیط‌های آزمایشی.

## امکانات سخت‌افزاری آنبورد

| بخش | مشخصات سخت‌افزاری | پروتکل اتصال |
| :--- | :--- | :--- |
| **سوکت ماژول MCU** | کانکتور دوطرفه ۳۰ پین استاندارد امیا | اتصالات تغذیه و GPIO |
| **درگاه کارت حافظه** | اسلات MicroSD با مقاومت‌های پول‌آپ خارجی | پروتکل SPI / SDIO ۴ بیتی |
| **کانکتور نمایشگر** | کانکتور FPC با ۱۲ پین برای نمایشگرهای ST7789 | گذرگاه SPI پرسرعت |
| **کلیدهای کاربردی** | ۴ عدد میکروسوئیچ تاکتایل با مدار فیلتر سخت‌افزاری | متصل به پایه‌های وقفه خارجی |
| **سوکت باتری** | کانکتور استاندارد JST-PH 2.0mm به همراه مدار شارژ | ریل باتری LiPo 3.7V |
