# نود سنسور بی‌سیم IoT امیا

سنسور نود کم‌مصرف برای پایش طولانی‌مدت شرایط محیطی انبارها، گلخانه‌ها و خطوط تولید.

## مشخصات فنی نود بی‌سیم

| پارامتر | مقدار | واحد | توضیحات |
| :--- | :--- | :--- | :--- |
| **سنسورهای داخلی** | دما، رطوبت، فشار هوا، شاخص گاز | — | پکیج BME688 کالیبره شده |
| **پروتکل رادیویی** | BLE 5.0 Mesh / فرکانس 2.4GHz | — | برد موثر تا ۱۰۰ متر در فضای باز |
| **باتری سازگار** | لیتیوم تیونیل کلرید (Li-SOCl₂) یا لیتیوم پلیمر | — | ظرفیت پیشنهادی: 1200mAh |
| **طول عمر تخمینی باتری** | بیش از ۲۴ ماه | — | با نرخ ارسال داده هر ۵ دقیقه |
| **جریان خواب عمیق** | 4.5 | µA | کل مدار شامل سنسور و پردازنده |

## حالات کاری و مصرف انرژی

| وضعیت عملکرد | مدت زمان | جریان مصرفی |
| :--- | :--- | :--- |
| **اندازه‌گیری سنسورها** | ۳۰ میلی‌ثانیه | 12 mA |
