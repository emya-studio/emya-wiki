# راهنمای توسعه نرم‌افزاری امیا

راهنمای گام‌به‌گام راه‌اندازی محیط‌های توسعه، تول‌چین‌ها، کامپایل فریم‌ور و استفاده از کتابخانه‌های نرم‌افزاری سخت‌افزار امیا.

## سرفصل‌های این بخش

| راهنما | موضوعات پوشش داده شده | مخاطب |
| :--- | :--- | :--- |
| **[پیکربندی محیط توسعه و SDK](/software/sdk-setup)** | نصب VS Code، افزونه ESP-IDF، کامپایلر GCC و ابزارهای خط فرمان | کلیه توسعه‌دهندگان |
| **[راهنمای فلش فریم‌ور و دیباگ](/software/flashing-guide)** | نحوه پروگرم، تنظیم بادریت، استفاده از esptool و مانیتورینگ سریال | توسعه فریم‌ور و تست |
| **[کتابخانه‌ها و درایورهای سخت‌افزاری](/software/drivers)** | راه‌اندازهای سنسورهای BME688، BMI270، نمایشگرها و ارتباطات شبکه | توسعه‌دهندگان اپلیکیشن |

---

## ابزارهای رسمی پشتیبانی‌شده

- **ESP-IDF v5.x**: چارچوب توسعه رسمی برای محصولات و بردهای بر پایه ESP32-S3.
- **PlatformIO**: محیط توسعه یکپارچه قابل نصب روی VS Code برای مدیریت آسان وابستگی‌ها.
- **Zephyr RTOS**: سیستم‌عامل بلادرنگ برای ماژول‌های کم‌مصرف و شبکه‌های پیشرفته مش.
