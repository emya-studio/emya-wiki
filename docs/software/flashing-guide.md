# راهنمای فلش فریم‌ور و دیباگ

دستورالعمل پروگرم کردن کدهای کامپایل‌شده روی سخت‌افزارهای امیا از طریق پورت USB و خط فرمان.

## ۱. شناسایی پورت سریال برد

برد را با کابل دیتای USB-C به رایانه وصل کنید:

- **در سیستم‌های لینوکس / مک**:
  ```bash
  ls /dev/tty.usb* /dev/ttyUSB*
  ```
- **در ویندوز**:
  از طریق **Device Manager** بخش Ports (COM & LPT) پورت اختصاص‌یافته (مثلاً `COM5`) را مشاهده کنید.

---

## ۲. دستور فلش با استفاده از idf.py

برای کامپایل، پروگرم روی برد و اجرای مانیتور سریال در یک دستور:

```bash
idf.py -p /dev/ttyUSB0 flash monitor
```

::: tip خروج از مانیتور سریال
برای خروج از محیط لاگ سریال ترمینال، کلیدهای `Ctrl + ]` را همزمان فشار دهید.
:::

---

## ۳. فلش با ابزار esptool بدون کامپایلر

در صورتی که فایل باینری فریم‌ور آماده (`firmware.bin`) را دارید، می‌توانید بدون نصب کامل SDK با ابزار پایتونی `esptool` برد را فلش کنید:

```bash
pip install esptool
```

```bash
esptool.py -p /dev/ttyUSB0 -b 921600 write_flash 0x10000 firmware.bin
```
