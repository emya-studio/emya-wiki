# ماژول‌های پردازشی MCU امیا

هسته‌های پردازشی استاندارد و ماژول‌های سیستم روی چیپ (SoC) مورد استفاده در پروژه‌های سخت‌افزاری امیا.

## فهرست ماژول‌های پردازشی

| نام ماژول | معماری هسته | فرکانس | ارتباطات بی‌سیم | لینک مستندات |
| :--- | :--- | :--- | :--- | :--- |
| **[ماژول ESP32-S3](/mcu-modules/esp32-s3)** | Xtensa LX7 Dual-Core | 240 MHz | Wi-Fi 4 + BLE 5.0 | [مشاهده مشخصات](/mcu-modules/esp32-s3) |
| **[ماژول کم‌مصرف Cortex-M](/mcu-modules/cortex-m)** | ARM Cortex-M0+ / M4 | 64 MHz | پروتکل‌های صنعتی باسیم | [مشاهده مشخصات](/mcu-modules/cortex-m) |

## استانداردهای تجمیع و پین‌اوت ماژول‌ها

ماژول‌های MCU امیا با ابعاد فیزیکی استاندارد، فوت‌پرینت قلع‌پذیری لبه‌ای (Castellated Holes) و خازن‌های فیلترینگ ورودی روی خود ماژول طراحی شده‌اند تا امکان لحیم‌کاری مستقیم بر روی بردهای اصلی (Motherboard) را بدون نیاز به مدارات جانبی پیچیده فراهم کنند.
