# ماژول پردازشی ESP32-S3

هسته پردازشی بی‌سیم با توان محاسباتی بالا برای پردازش صوت، تصویر و ارتباطات اینترنت اشیا.

## مشخصات فنی ماژول

| پارامتر | مقدار | واحد | توضیحات |
| :--- | :--- | :--- | :--- |
| **هسته پردازشی** | دو هسته‌ای ۳۲ بیتی Xtensa LX7 | — | تا 240 مگاهرتز فرکانس کاری |
| **حافظه SRAM** | 512 | KB | حافظه داخلی تراشه |
| **حافظه PSRAM** | 2 یا 8 | MB | حافظه رم خارجی پرسرعت با درگاه Octal SPI |
| **حافظه Flash** | 8 یا 16 | MB | جهت ذخیره فریم‌ور و فایل‌سیستم SPIFFS |
| **ولتاژ کاری** | 3.0 تا 3.6 | V | ولتاژ نامی 3.3 ولت |
| **پایه‌های GPIO** | تا 44 پایه در دسترس | — | با قابلیت مالتی‌پلکس پیشرفته |

---

## پین‌های بحرانی و عملکردهای خاص

- **`GPIO0`**: پین انتخاب مد بوت (Boot Strapping). در زمان ریست، بالا بودن این پین باعث اجرای عادی برنامه و پایین بودن آن موجب ورود به مد دانلود فلش می‌شود.
- **`GPIO19 / GPIO20`**: خطوط USB D- و USB D+ برای اتصال مستقیم به کنترلر USB داخلی.
- **`GPIO43 / GPIO44`**: خطوط پیش‌فرض UART0 جهت نمایش پیام‌های بوت‌لودر.
