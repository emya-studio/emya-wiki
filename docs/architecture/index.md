# معماری کلی سخت‌افزار امیا

توپولوژی الکتریکی، زیرسیستم‌ها و ساختار کلان بردهای الکترونیکی امیا.

## بلوک‌دیاگرام زیرسیستم‌ها

```
┌─────────────────┐       ┌──────────────────────┐
│  ورودی USB-C 5V │───┬──▶│ مدار شارژر و مسیردهی │
└─────────────────┘   │   │  (TP4056 / BQ24075)  │
┌─────────────────┐   │   └──────────┬───────────┘
│ باتری لیتیومی   │───┘              │ VSYS (3.0V - 4.2V)
│ (3.7V - 4.2V)   │                  ▼
└─────────────────┘       ┌──────────────────────┐
                          │ مبدل باک TPS62840     │──▶ ریل دیجیتال 3.3V ──▶ ESP32-S3 + حافظه Flash
                          ├──────────────────────┤
                          │ رگولاتور AP2112K LDO │──▶ ریل آنالوگ 3.3V  ──▶ سنسورها (BME688, BMI270)
                          └──────────────────────┘
```

## زیرسیستم‌های اصلی

- **[درخت توزیع توان (Power Tree)](/architecture/power-tree)**: ریل‌های ولتاژ، بودجه مصرف جریان در حالات کاری، تحلیل طول عمر باتری.
- **[مشخصات و محدودیت‌های حرارتی](/architecture/thermal)**: حداکثر دمای پیوند قطعات، مساحت مس و ویاهای خنک‌کننده، آستانه‌های قطع خودکار حرارتی.
